# 精灵图

**这个目录是可选的。** 画面里的海鸥、食材、障碍现在都由 `tools/scenery.py`
和 `tools/icons.py` 的字符网格生成(见 `js/game/pixels.js`),不放任何 PNG 也是完整的。

这里留的是「以后想换成手绘图集」的口子:图集放这里,文件名和 `js/main.js` 顶部的
`SPRITES` 清单对应。**图不存在不会报错** —— `SpriteBook` 加载失败时
自动退回内置的像素图,所以随时可以只替换其中一张。

## 规格

| 项 | 约定 |
|---|---|
| 格子 | 正方形,同一张图集内所有帧同尺寸。海鸥用 `32×32` |
| 排列 | 一行一个动画,从左到右是帧序 |
| 背景 | 透明 PNG |
| 锚点 | **每帧角色重心必须落在格子同一位置**,否则播放时会抖。内置那只的做法是身体只画一次、四帧只换翅膀 |

## 当前清单(js/main.js)

`sprites/waou.png`,格子 32×32:

```
row 0  idle  4 帧  6fps    待机,轻微起伏
row 1  fly   6 帧  12fps   飞行,翅膀一个完整扇动周期
row 2  hurt  2 帧  8fps    受击,不循环
```

即图集尺寸是 `192×96`(6 帧 × 32 = 192 宽,3 行 × 32 = 96 高),
不足的格子留空即可。

## 加一个新动画

1. 在图集里加一行
2. 在 `js/main.js` 的 `SPRITES` 里补一条 `{ row, frames, fps }`

不用改渲染代码。
